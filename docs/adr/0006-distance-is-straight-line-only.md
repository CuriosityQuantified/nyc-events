# Distances are straight-line, never travel time

Proximity to subway stations is expressed as straight-line distance and labelled as such — `0.3 mi from Grand Army Plaza (2·3)`. The application never displays walking time, transit time, or a route.

Straight-line distance is a geometric fact derivable from coordinates we already hold. Travel time is a routing claim requiring a source we do not have, and presenting one would breach the project's core rule that unverified information is never stated as fact. This will read as an odd limitation to anyone used to consumer mapping apps; it is deliberate.
