# The HTML prototype is a sketch, not a contract

`nyc-events-mvp-v2.html` and its sibling are treated as design sketches. Their visual direction — colour, type hierarchy, card layout, the List/Map toggle and bottom navigation — carries forward; their markup and hand-rolled state machine do not.

This contradicts `DESIGN-MANIFEST.json`, which asserts "Preserve visual hierarchy, responsive behavior, and interactive states from this screen" and a one-file-per-screen policy. That manifest was generated by a design-export tool, not authored as a decision, and a literal port of vanilla-JS screen switching into React would fight the framework. The record exists so nobody later reads the manifest and "restores" fidelity we chose to drop.
