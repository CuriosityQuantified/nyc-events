# EventMatch NYC API contract

`openapi.json` is the shared backend/frontend authority. Golden responses are deliberately hand-authored from the committed NYC Parks CSV reference snapshot; they are not generated by the mock.

## Run the mock

```bash
python3 contracts/mock_server.py
```

The server listens on `127.0.0.1:4010` by default. Override the port with `--port`; `--host` accepts loopback only because this fixture server is not production-hardened.

```bash
curl 'http://127.0.0.1:4010/events?borough=Manhattan&category=Fitness'
curl 'http://127.0.0.1:4010/events/2%2C146%2C733'
curl 'http://127.0.0.1:4010/freshness'
```

## Validate

```bash
uv run contracts/validate_contract.py
python3 -m unittest discover -s contracts/tests -v
```

Validation resolves each operation's `x-golden-response`, validates it against that operation's 200 response schema, checks the required API surface and Facet parameters, and blocks vocabulary that conflicts with `CONTEXT.md`.

The later real-data integration ticket may regenerate the golden payload values. It must keep this schema contract compatible rather than creating a lane-specific variant.
